
# 0302 — Histogram Equalization

Project 03-02 of the Digital Image Processing course (Gonzalez & Woods, Section 3.3.1).
The program computes the histogram of an image, builds the histogram-equalization
transformation s = T(r) from the cumulative distribution, and applies it to Fig. 3.8(a),
a dark fractured-spine MRI. It saves a figure with the original image, its histogram,
the transformation function, the equalized image and its histogram.

**Run:** `python histogram_equalization.py` (`numpy`, `matplotlib`, `pillow`).
